# From nearby parcels to a diligence decision

| Delivery order | Behavior | Acceptance check |
| --- | --- | --- |
| 1. Accurate coverage | Count wholly and partially missing measures separately. Exclude inapplicable and unavailable states from missing counts. Preserve zero. | Compare two sites with no recorded power, one with missing asking, and one measured zero. |
| 2. Save a decision | The owner of a saved comparison can record a preferred site or hold all sites, explain why, and cite site-specific figures. Personal and team visibility follows the saved view. | A reviewer saves a shared decision, a teammate reopens it, and a private view stays private. |
| 3. Revisit the evidence | Keep the original cited values, author and time alongside the current figures. Link changes to the source panel and the matching evidence follow-up. | Add sourced evidence in an isolated fixture. Reopen the comparison and inspect the changed figure and request. Replaying a save produces one decision. |
| 4. Browse nearby sites | Show an expandable list of eligible sites in the current city viewport. Use the same selection, fit figure and comparison controls as a pin. Start collapsed on a phone. | Select two nearby sites from the list, inspect the comparison, and return to the original map extent. |
| 5. Release | Run unit, database, desktop and phone browser checks. Review fixture screenshots, merge and verify the published build. | Exercise writes with synthetic accounts and use read-only navigation in production. |
